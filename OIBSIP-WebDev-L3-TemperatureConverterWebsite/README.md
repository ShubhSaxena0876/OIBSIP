# Temperature Converter Website

## Level 1 – Task 3

### Objective

Build a responsive and interactive temperature converter that converts values between Celsius, Fahrenheit, and Kelvin using HTML5, CSS3, and JavaScript.

### Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

### Features

* Numeric input field with input validation
* Temperature unit selection (Celsius, Fahrenheit, Kelvin)
* Converts temperature to all supported units
* Convert button to perform the calculation
* Displays converted values with correct unit labels
* Handles invalid inputs and absolute zero violations
* Clean and responsive user interface
* Mobile-friendly design

### Project Structure

```text
Task3-Temperature-Converter/
│── index.html
│── style.css
│── script.js
│── README.md
└── screenshots/
    └── temperature-converter.png
```

### How to Run

1. Download or clone the repository.
2. Open the **Task3-Temperature-Converter** folder.
3. Open `index.html` in any modern web browser.
4. Enter a temperature value, select the input unit, and click the **Convert** button to view the converted results.

### Screenshot

Add a screenshot of the completed temperature converter inside the **screenshots** folder and name it `temperature-converter.png`.
