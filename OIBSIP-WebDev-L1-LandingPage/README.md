# Landing Page

## Level 1 – Task 1

### Objective

Build a visually polished and responsive static landing page for a product and service Cursor AI using only **HTML5** and **CSS3**.

### Technologies Used

* HTML5
* CSS3

### Features

* Fixed/Sticky navigation bar with multiple navigation links
* Hero section with a headline, subhead line, and call-to-action button
* Features section
* About section
* Responsive design using CSS Flexbox/Grid
* Footer with placeholder contact and social media links
* Consistent colour palette and typography
* Mobile-friendly layout

### Project Structure

```text
Task1-Landing-Page/
│── index.html
│── style.css
│── README.md
└── screenshots/
    └── landing-page.png
```

### How to Run

1. Download or clone the repository.
2. Open the **Task1-Landing-Page** folder.
3. Double-click `index.html` or open it in any modern web browser.
