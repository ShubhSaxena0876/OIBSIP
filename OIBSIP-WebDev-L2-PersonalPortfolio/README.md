# Personal Portfolio

## Level 1 – Task 2

### Objective

Create a responsive personal portfolio website that showcases my skills, projects, and contact information using HTML5 and CSS3.

### Technologies Used

* HTML5
* CSS3
* JavaScript (Optional)

### Features

* Profile/Hero section with name, role, and profile image/avatar
* About Me section describing my background and interests
* Skills section displaying technical skills
* Projects section with project cards and GitHub link placeholders
* Contact section with email and social media links
* Smooth scrolling navigation
* Consistent colour scheme and typography
* Fully responsive design for desktop and mobile devices

### Project Structure

```text
Task2-Personal-Portfolio/
│── index.html
│── style.css
│── README.md
├── images/
│   └── profile.jpg
└── screenshots/
    └── portfolio-home.png
```

### How to Run

1. Download or clone the repository.
2. Open the **Task2-Personal-Portfolio** folder.
3. Open `index.html` in any modern web browser.

Added screenshots of the completed portfolio homepage inside the **screenshots** folder and name it `portfolio-home.png`.
